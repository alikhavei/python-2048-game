# بازی 2048 با پایتون (Tkinter)

این پروژه یک پیاده‌سازی ساده و جذاب از بازی محبوب **2048** است که با استفاده از زبان برنامه نویسی پایتون و کتابخانه گرافیکی استاندارد `Tkinter` ساخته شده است.

## ویژگی‌ها
- طراحی گرافیکی مشابه نسخه اصلی بازی.
- سیستم امتیازدهی (نمایش بیشترین عدد ساخته شده).
- قابلیت شروع مجدد بازی (Retry).
- مدیریت ورودی‌های کیبورد برای حرکت در چهار جهت w بالا s پایین d راست a هم چپ.
- تشخیص خودکار وضعیت برد یا باخت (Game Over).

## نحوه اجرا
برای اجرای بازی، ابتدا مطمئن شوید که پایتون روی سیستم شما نصب است، سپس دستور زیر را در ترمینال یا CMD اجرا کنید:

2048.py
